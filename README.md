# 🚀 Crypto Project

## 📖 Project Description
This is a MERN Stack Crypto Project that allows users to view cryptocurrency information. The application uses React for the frontend, Node.js and Express for the backend, and MongoDB for data storage.

## ✨ Features
- User-friendly interface
- Crypto data display
- Secure backend APIs
- Responsive design
- Database integration

## 🛠 Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB
- HTML
- CSS
- JavaScript
- Git & GitHub

## ⚙️ Installation

### Clone the repository
```bash

```

### Install frontend
```bash

npm install
npm start
```

### Install backend
```bash
cd server
npm install
npm start
```
